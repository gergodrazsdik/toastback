# Support

toastback is an open-source project with one maintainer. There is no guaranteed support.

- **Questions and problems:** check the README's [Troubleshooting](README.md#troubleshooting) and
  [Limitations](README.md#limitations) sections and the existing issues first, then open an
  [issue](https://github.com/gergodrazsdik/toastback/issues/new/choose). `toastback doctor` and `toastback log` output
  helps.
- **Security problems:** never in a public issue. See [SECURITY.md](SECURITY.md).
- **Contributions:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Leave tokens, passwords and other secrets out of the specs, logs and command lines you paste.
